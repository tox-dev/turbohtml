``to_markdown()`` writes breaks inside emphasis as hard breaks again when visible text separates them, so
``<em>[Image OCR]<br>text<br>[End OCR]</em>`` becomes ``*\[Image OCR\]  \ntext  \n\[End OCR\]*`` instead of keeping raw
``<br>`` tags; only breaks with nothing visible between them, which would end the paragraph, stay tags.
